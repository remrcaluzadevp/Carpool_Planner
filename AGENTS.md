# AGENTS.md

Guidance for developers and AI agents working on Carpool Planner.

## What this is

A student carpool planner. A **trip** is shared by link (`/trip/<id>`); anyone with the link can add **cars**
(driver + passenger seats) and **riders**, assign riders to seats, and download the plan. There are no user
accounts — the random, unguessable trip id is the access key.

## Architecture

| Layer       | Where                                       | Notes                                                                 |
| ----------- | ------------------------------------------- | --------------------------------------------------------------------- |
| Pages       | `src/routes/index.tsx`, `src/routes/trip.$tripId.tsx` | Landing + create form; trip board (loader → `getTripBoard`)  |
| Server code | `src/lib/trips.functions.ts`                | TanStack Start `createServerFn` handlers, all validated with zod      |
| Database    | `db/schema.ts`, `db/index.ts`               | Netlify Database via `drizzle-orm/netlify-db` (`@beta` dist-tag)      |
| Migrations  | `netlify/database/migrations/`              | Generated by `drizzle-kit generate --name …`; applied on deploy       |
| Downloads   | `src/lib/downloads.ts`, `src/components/trip/print-sheet.tsx` | CSV / ICS / TXT built client-side; print uses `@media print` |
| Installable | `public/manifest.webmanifest`, `public/sw.js`, `src/components/install-app.tsx` | PWA install prompt + network-first SW |

## Data model

- `trips` — `id` is a 10-char random slug. `time_zone` is the organizer's IANA zone at creation.
- `cars` — `seats` counts **passenger** seats only (driver excluded). Deleting a car sets its riders' `car_id`
  to null (back to the waitlist).
- `riders` — `car_id` null means waitlisted. Seat order within a car is rider creation order.

## Conventions and non-obvious decisions

- **Dates render in the trip's time zone with a fixed `en-US` locale** (`src/lib/format.ts`). This keeps SSR and
  client output identical (no hydration mismatch) and shows everyone the organizer's local time. The edit
  dialog's `datetime-local` inputs use the browser zone, which is fine because they render only on the client.
- Every mutating server function re-checks that the car/rider belongs to the trip and enforces seat capacity
  server-side; the UI checks are only for fast feedback.
- After a mutation the trip page calls `router.invalidate()` (see `run()` in `trip.$tripId.tsx`). The board
  also refreshes when the tab regains visibility so collaborators' changes show up.
- Dropdown menus that open dialogs use `modal={false}` to avoid Radix's stuck `pointer-events` issue.
- The service worker never caches `/_serverFn` calls; only navigations, `/assets/*`, and image CDN responses.
- Theme colors live in `src/styles.css` (`--primary` navy, `--accent`/`--sun` sunflower, `--coral`). Fonts:
  Bricolage Grotesque (`font-display`), Figtree (body), DM Mono (`font-ticket` for boarding-pass labels).
- Reference images through the Image CDN: `/.netlify/images?url=/img/<file>&w=<width>&fm=webp`.
- Read `localStorage` only inside `useEffect` (SSR).
- Imports from `src` use the `@/` alias; `db/` is imported relatively.

## Schema changes

1. Edit `db/schema.ts`.
2. `npx drizzle-kit generate --name <imperative_snake_case>`.
3. Never hand-edit or modify migrations that have been applied; roll forward instead.
